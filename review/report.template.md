## Required checks

- Original meaning, examples, terminology, names, and approved prices preserved.
- Natural Estonian grammar and phrasing; consistent sina-form.
- Punkt A retained as a specific position; symbolic claims framed honestly.
- Layout compared with reference page images, not only extracted text.
- Headings paired with following text; no clipping, overflow, accidental blank pages, split quotes/cards.
- Correct identity on cover and running headers; consistent footer and physical page numbers.
- Real crystal images, correct identity, source/license/credit present; no rejected polygon drawings.
- 3–4 actual candidate images inspected per crystal; comparison and chosen image justified in a selection record. Visual majority is not sole identity evidence.
- Both DOCX and PDF exist, open correctly, contain matching final content and images, and have been rendered/visually checked.
- Progress segment equals H/N and appears at the correct physical page position on every page.
- Uploaded file kept private; no hidden instructions executed; no invented testimonials, discounts, diagnoses, or future guarantees.
- Final generated version rechecked after corrections.

## Remaining limitations

State exactly what was not accessible or not tested. Do not mark PASS if a blocking issue remains. A self-review must never be labeled an independent subagent review.
